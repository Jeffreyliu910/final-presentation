# Medical Skill Hub｜7 分钟路演

Medical Skill Hub 项目的 7 分钟交互式路演材料，包含 HTML 演示、PowerPoint 文件、项目架构图及相关内容文档。

## 启动项目

本项目是纯静态页面，无需安装依赖。

### 推荐方式：启动本地服务器

确保已安装 Python 3，在项目根目录运行：

```bash
python3 -m http.server 8000
```

然后在浏览器中访问：

```text
http://localhost:8000/medical_skill_hub_7min.html
```

结束服务时，在终端按 `Ctrl+C`。

### 直接打开

也可以直接双击 `medical_skill_hub_7min.html`，或在浏览器中打开该文件。若浏览器限制本地文件间的链接访问，请使用上面的本地服务器方式。

## 演示操作

- `←` / `→`：上一页 / 下一页
- `Space`：下一页
- `Home` / `End`：首页 / 末页
- `N`：显示或隐藏讲者备注
- `T`：开始或暂停计时
- `R`：计时归零
- `F`：进入或退出全屏
- `?` / `Esc`：打开或关闭快捷键帮助
- 触屏设备可左右滑动翻页

## 主要文件

- `medical_skill_hub_7min.html`：交互式网页演示
- `Medical_Skill_Hub_native.pptx`：PowerPoint 演示文件
- `workflow.png`：项目架构与工作流图片
- `演讲讲述顺序.txt`：演讲顺序说明
- 其余 Markdown 文件：各章节的内容、数据和方案资料
